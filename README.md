# SharePlate – Food Waste Management & Donation System

Clickable website prototype for a college Design Thinking project.

**Tagline:** Don't waste food. Share it with care.

## Run it
Open `index.html` in any browser. No install or server needed.

## Demo flows
- **Donor:** Home → Login/Register (Food Donor) → Dashboard → Donate Food → Submit → Confirmation → Track Donation
- **NGO / Collector:** Home → Login/Register (NGO / Food Collector) → Dashboard → Find Food → View Details → Request Collection

## Important
This is a prototype. All data is fictional. Login, form submission, partner verification and donation tracking are simulated; there is no backend or database.

## Files
- `index.html` – the full prototype (HTML, CSS, JavaScript in one file)
